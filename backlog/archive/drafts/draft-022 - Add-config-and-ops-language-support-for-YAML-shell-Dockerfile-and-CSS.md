## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Second expansion wave for modern repos. Add useful retrieval coverage for common config and operational files such as YAML, shell/bash, Dockerfile, and CSS. These languages may not all need the same symbol model as Python or TypeScript, so the design should distinguish where full parser-backed symbol extraction is worthwhile versus where structured headings, rules, blocks, or file-level fallback records are sufficient.

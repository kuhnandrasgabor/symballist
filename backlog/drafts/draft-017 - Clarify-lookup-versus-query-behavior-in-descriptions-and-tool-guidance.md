## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Exact symbol lookup is strong, but the distinction between lookup and query is still easy for agents to miss because both commands accept similar inputs. Track work to make the behavioral difference explicit in help text, tool descriptions, generated manifests, and onboarding guidance: lookup should clearly mean best-match-plus-context, while query should clearly mean ranked candidate exploration.
